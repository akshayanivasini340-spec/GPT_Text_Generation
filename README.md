🤖 GPT-Text-Generator

Text Generation Using GPT Model with Streamlit.

📌 Project Description

This project is an AI Text Generator that uses a GPT-2 model to generate text from a given prompt.

The application is created using Python, Hugging Face Transformers, and Streamlit.

🛠️ Technologies Used

Python

GPT-2

Hugging Face Transformers

Streamlit

PyTorch


⚙️ Features

Simple and user-friendly interface

Accepts text prompts from the user

Generates AI-based text

Uses GPT-2 for text generation

Displays generated text

🚀 How to Run

Install the required libraries:

py -m pip install transformers torch streamlit

Run the application:

py -m streamlit run app.py

Open the Local URL shown in the terminal.
